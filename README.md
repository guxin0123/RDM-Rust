# RDM Rust

# 项目介绍
这是一个基于Rust的Windows远程桌面RDP连接管理项目，用于管理Windows远程桌面RDP连接。
Rust + GPUI ，gpui-kit 组件库 , shadcn 风格。无 WebView 组件。

项目最终被编译为一个独立的可执行文件，无需安装任何依赖项。

## 构建
```bash
cargo build --release
```
编译产物为 `target/release/` 下的独立 exe，拷贝至任意目录即可运行。

## 数据存储
连接数据存储在exe 目录下的 connections.json 文件中,密码使用 Windows DPAPI（CryptProtectData）加密存储。
加密密钥由 Windows 按当前用户自动生成和管理，不落盘、不随程序分发，加密后的数据仅能被同一台机器上的同一 Windows 用户解密。

## 远程连接（mstsc 集成）
连接远程服务器时，通过 mstsc 打开远程桌面连接窗口，完整流程如下：

1. 解密 connections.json 中该服务器的密码（DPAPI CryptUnprotectData）
2. 写入系统凭据，使 mstsc 免密登录：
   ```
   cmdkey /generic:TERMSRV/<服务器地址> /user:<用户名> /pass:<明文密码>
   ```
3. 启动远程桌面连接：
   ```
   mstsc /v:<服务器地址>:<端口>
   ```
4. 远程桌面窗口关闭后，删除已写入的凭据：
   ```
   cmdkey /delete:TERMSRV/<服务器地址>
   ```

说明：
- 凭据仅在连接存续期间存在，程序异常退出时会在下次启动时清理遗留的 TERMSRV 凭据
- 若用户保存的密码为空，则跳过第 2 步，由 mstsc 弹出系统登录框手动输入

## 界面功能

项目主窗口上方工具栏包含以下功能：
- 新增分组
- 新增服务器
- 编辑服务器
- 删除服务器
- 连接到选中服务器
- 刷新服务器列表（重新从 connections.json 读取数据并刷新列表显示，同时检测各服务器延迟）
- 导入连接
- 导出连接

窗口中心区域显示连接列表：
- 双击连接列表中的服务器，即可连接到该服务器
- 右键点击连接列表中的服务器，弹出上下文菜单，包含：连接、编辑服务器、删除服务器
- 右键点击连接列表中的分组，弹出上下文菜单，包含：新增服务器、重命名分组、删除分组

服务器延迟显示：
- 每个服务器条目显示到该服务器的延迟（单位 ms）
- 延迟通过 TCP 连接服务器的 RDP 端口测量（从发起连接到建立 TCP 连接的耗时），比 ICMP ping 更能反映 RDP 实际可用性
- 超时时间 3 秒，超时或连接失败显示"离线"
- 点击"刷新服务器列表"时对所有服务器并发检测，检测过程中显示加载状态，不阻塞界面操作

分组规则：
- 仅支持单层分组，不支持嵌套
- 未指定分组的服务器归入默认分组"默认"
- 删除分组时，组内服务器移入默认分组，不随之删除

新增/编辑服务器窗口：
- 输入或选择分组名称
- 输入服务器名称
- 输入服务器IP地址或域名+端口号(默认3389)
- 输入用户名
- 输入密码
- 点击确定按钮，即可保存

## 导入导出功能
- 导出：选择导出路径，将连接列表导出为 JSON 文件
  - 由于 DPAPI 密文仅能被本机当前用户解密，导出时密码字段默认不导出（置空）
  - 可选：导出时输入一个导出密码，使用该密码对所有服务器密码进行对称加密（如 AES-GCM）后写入导出文件
- 导入：选择 JSON 文件，校验文件格式
  - 若文件包含加密的密码字段，需输入导出时使用的密码进行解密
  - 解密后的密码在导入时使用 DPAPI 重新加密后存入 connections.json
  - 导入的分组与服务器合并到现有列表，重名服务器按用户选择覆盖或跳过
